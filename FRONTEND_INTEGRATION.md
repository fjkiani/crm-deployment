# CRM Frontend (crm-deployment)

Vue SPA source lives in **this repo** under `frontend/`. Build output goes to `crm/public/frontend/` and `crm/www/crm.html`.

## Source layout

```
crm-deployment/
  frontend/src/pages/          ← edit Vue pages here
  frontend/src/router.js       ← routes
  frontend/src/components/     ← shared components + AppSidebar
  crm/public/frontend/         ← built assets (do not edit by hand)
  crm/www/crm.html             ← SPA shell (generated by yarn build)
```

## Build

```bash
cd crm-deployment
yarn install
yarn build
```

Then commit `frontend/` source changes and rebuilt `crm/public/frontend/` + `crm/www/crm.html` before pushing to Frappe Cloud.

## 🛠️ Troubleshooting

- "Invalid page or not permitted to access"
  - Ensure you are logged in
  - Confirm `website_route_rules` include `/crm` and `/crm/<path>`
  - Clear Cache on Frappe Cloud and reload
- Blank page after build
  - Rebuild frontend (`yarn build`) and verify `crm/www/crm.html` updated
  - Ensure assets are under `/assets/crm/frontend/` (handled by build script)
- Farfalle requests fail
  - Set `VITE_FARFALLE_BASE_URL` at build-time, or run Farfalle locally at `http://localhost:8000`
